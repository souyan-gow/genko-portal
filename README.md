# GENKO ドキュメント

原稿用紙エディタ「GENKO」の利用者向けドキュメントのサイトです。
GitHub Pages で公開しています。アプリとは別のリポジトリなので、アプリが止まってもこのサイトは見られます。

## 構成

```
index.html            トップページ（ドキュメントの一覧）
assets/style.css      共通の見た目（ライト・ダーク）
docs/
  guide.html          利用ガイド
  notation.html       記法の早見表
  faq.html            困ったときは
  glossary.html       用語集
  plan.html           企画書
  basic-design.html   基本設計書
  detail-design.html  詳細設計書
  tech-spec.html      技術仕様書
  updates.html        更新のお知らせ
  data-safety.html    データの守り方
```

ビルドの手順はありません。HTML をそのまま公開しています。

## 注意

このリポジトリは公開されています。ユーザーUID、Firebase の設定値、アプリの公開先のアドレスなど、外に出したくない情報は書かないでください。
